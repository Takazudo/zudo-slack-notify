:::note[Keep secrets out of source control]
Keep tokens, relay keys, channel IDs, and Cloudflare account details out of source control, issues, pull requests, and logs. Secrets live as Worker secrets, plus GitHub repository secrets if you deploy with GitHub Actions. See [Secrets and rotation](./secrets/) for the full inventory.
:::
